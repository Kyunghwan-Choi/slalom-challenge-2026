# Troubleshooting

For questions about the rules, modes, or action interface, check [Questions and answers](Q_AND_A.md). For setup and execution instructions, see [Installation](INSTALL.md) and [Running](RUNNING.md).

Confirmed troubleshooting entries will be added as issues are reproduced. For an installation or simulator issue, email [fairytale@kaist.ac.kr](mailto:fairytale@kaist.ac.kr) with your Windows version, the command you ran, the full error message, and `result.json` if the run produced one.
