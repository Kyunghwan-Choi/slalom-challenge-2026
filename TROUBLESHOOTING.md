# Troubleshooting

For questions about the rules, modes, or action interface, check [Questions and answers](Q_AND_A.md). For setup and execution instructions, see [Installation](INSTALL.md) and [Running](RUNNING.md).

Confirmed troubleshooting entries will be added as issues are reproduced. For an installation, simulator, or scoring issue, email [fairytale@kaist.ac.kr](mailto:fairytale@kaist.ac.kr) with:

- The repository commit or downloaded ZIP version, Windows version, and exact run command.
- The course JSON or `scenario_id`, seed, and mode used.
- The full error message and `result.json`, if either was produced.
- A minimal reproducing controller or plan, when possible.
